## 2. Cryptographic License Key Format

License keys are generated by your Developer CLI tool (`cmd/license-cli`) using **Ed25519** asymmetric keys:

```bash
# Generate a new 10-Seat Professional License for customer
go run ./cmd/license-cli \
  --customer-id="cust_acme_001" \
  --domain="app.acme.com" \
  --tier="PRO_10" \
  --human-seats=10 \
  --ai-seats=5 \
  --valid-days=365 \
  --out-key=license.key
```

## 3. Local Seat & Agent Limit Enforcement

Seat enforcement happens **100% locally inside the customer's container** during the `SupportLogin` request:

```go
func (s *LicenseService) ValidateAgentSeatAllowance(ctx context.Context, isAIAgent bool) error {
	lic, err := s.GetActiveLicense(ctx)
	if err != nil || lic.IsExpired() {
		return errors.New("LICENSE_INVALID: License key is invalid or expired")
	}

	activeHumanCount, activeAICount, err := s.grantRepo.CountActiveAgents(ctx)
	if err != nil {
		return err
	}

	if isAIAgent {
		if activeAICount >= lic.MaxAIAgents {
			return errors.New("AGENT_LIMIT_EXCEEDED: Maximum AI Agent seat limit reached for your plan tier")
		}
	} else {
		if activeHumanCount >= lic.MaxHumanAgents {
			return errors.New("AGENT_LIMIT_EXCEEDED: Maximum Human Support Agent seat limit reached for your plan tier")
		}
	}

	return nil
}
```

## 4. Telemetry Heartbeat & Anti-Piracy Protocol

To prevent multi-instance container duplication or unauthorized server cloning, GrantSupport containers send an encrypted heartbeat ping once per 24 hours to your central licensing hub.

### 4.1 Telemetry Payload (`POST https://licensing.yourcompany.com/v1/telemetry/ping`)
```json
{
  "license_id": "lic_994821a_2026",
  "customer_id": "cust_acme_001",
  "machine_fingerprint": "SHA256(CPU_UUID + MAC_ADDRESS)",
  "active_human_agents": 4,
  "active_ai_agents": 2,
  "total_grants_issued_24h": 14,
  "timestamp": 1753880400
}
```

### 4.2 Offline Grace Period Protocol
* **Normal State**: Container pings server every 24 hours. Server returns `status: "ACTIVE"`.
* **Network Interruption**: If customer's internet goes down, container enters **Offline Grace Mode** for up to **7 days** without disrupting support access.
* **Expired Grace Period**: After 7 consecutive days of missed telemetry pings, the container switches to `READ_ONLY` mode until connectivity is restored or an offline air-gapped key is loaded.
